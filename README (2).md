# Threat Hunting Training Platform
### Wazuh SIEM · KQL Query Practice · MITRE ATT&CK · Live Lab Environment

An interactive, self-paced threat hunting training platform with two complementary components — a browser-based web trainer and a full live Wazuh lab environment students run locally on their own machine.

---

| 2 | **Live Lab** (local Docker) | Spin up real Wazuh, hunt through randomized training data in the actual interface |

## Live Lab Environment

A Docker-based Wazuh stack that runs on your local machine. Every time you start it, a Python script injects a fresh set of randomized training events — different IoC values each run so students cannot memorize answers.

### Requirements (Windows)
- Windows 10 or 11 (64-bit)
- [Docker Desktop for Windows](https://www.docker.com/products/docker-desktop/) — free
- 8GB RAM minimum
- 15GB free disk space

### Setup

1. Install Docker Desktop and make sure it's running
2. Download or clone this repository
3. Open **PowerShell as Administrator**
4. Navigate to the `lab` folder:
   ```powershell
   cd path\to\Threat_Hunting_With_Wazuh\lab
   ```
5. Run the setup script:
   ```powershell
   .\setup.ps1
   ```
6. Wait 3-5 minutes while Wazuh downloads and starts
7. The script opens `https://localhost` automatically when ready

**Login:** `admin` / `SecretPassword`

### Get your randomized IoC values

After setup, run this to see the specific values injected into your session:
```powershell
docker logs log-injector
```
This shows your attacker IP, compromised username, dropper filename, pipe name, and exfil port for this run.

### Live Lab Guide

Open `lab-guide/index.html` in your browser for step-by-step hunting instructions for each scenario in the real Wazuh interface.

### Stop the lab
```powershell
docker-compose down
```

## How the randomization works

Each time `setup.ps1` runs, `inject-logs.py` generates new values for every IoC — attacker IP, domain username, dropper executable name, named pipe identifier, Apache module name, credential harvest filename, archive name, and exfiltration port. The attack patterns and Wazuh field names stay the same. Only the specific values change. This forces students to actually hunt rather than recall memorized answers.

---

## Log Data Notice

All IoC values are procedurally generated and fictional. Attack patterns, Wazuh rule IDs, Sysmon event IDs, and KQL field names reflect a real Wazuh 4.7 deployment with Sysmon integration.
